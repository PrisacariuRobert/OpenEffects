# OpenEffects

**Open-source motion graphics, driven by the AI agent you already use.**

OpenEffects is a cross-platform motion graphics and compositing app (an open-source alternative to tools like After Effects) built for AI agents. Describe the animation you want and your agent (Claude Code, Codex, OpenCode, or a local model) builds it on a real timeline. You can then tweak every keyframe by hand.

- **Bring your own agent.** Like [T3 Code](https://github.com/pingdotgg/t3code), OpenEffects runs the agent CLIs you already have installed and signed in to. No extra account, no API bill, and support for local models.
- **Projects are plain text + git.** Every AI edit can be diffed, reviewed and undone per turn.
- **MCP-first.** Any MCP-capable agent can create layers, set keyframes, apply effects, and *render frames to check its own work*.
- **WebGPU engine.** Real-time preview, export to MP4/WebM/GIF/PNG.
