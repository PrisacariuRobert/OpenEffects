The open-source alternative to Claude Motion

Your AI agent animates it. You finish it.

OpenEffects turns the coding agent you already use (Claude Code, Codex or OpenCode, with any model) into a motion designer that works on a real timeline. Every shape, keyframe and easing curve stays editable. Export video for people and Lottie for apps. Free, MIT-licensed, on your machine.

00:00:00Workflow

Prompt it, then direct it.

Describe it

Type what you want in the agent panel. Your own Claude Code, Codex or OpenCode login does the work. Cheap models like Haiku cost cents per animation.

Watch it build

The agent edits real layers through OpenEffects' MCP tools, renders frames to check its own work, and you see every change live.

Finish by hand

Drag keyframes, shape easing in the graph editor, snap to beat markers, undo any AI turn. Then export.

00:20:00Compare

Same idea as Claude Motion. Open to everyone.

Claude Motion showed that AI motion graphics should be code, not generated footage: every frame exact, every detail changeable. OpenEffects agrees, and runs that idea on any agent, any plan, on your own machine.

00:31:00Get started

Running in two minutes.

# needs Node 20+, pnpm, ffmpeg and one agent CLI (claude, codex or opencode) git clone https://github.com/PrisacariuRobert/OpenEffects && cd OpenEffects pnpm install && pnpm build:web pnpm oe init ~/my-animation pnpm oe dev ~/my-animation # opens the editor pnpm oe import loader.json ~/lottie # or start from a Lottie file
